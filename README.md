# DSH Universe

> Plugin marketplace and ecosystem hub for DeepSeek Harness.

DSH Universe is the open ecosystem hub for **DeepSeek Harness (DSH)** — a continuously updated plugin marketplace, curated reviews, and open-source tooling.

**Main site: [duink.com](https://duink.com)**

## Quick start

```bash
npm install -g @dsh-universe/cli   # or: pip install dsh-universe
```

Explore the ecosystem: [plugins](https://duink.com/plugins) · [AI news](https://duink.com/news) · [comparisons](https://duink.com/compare/)

## Contributing

- **Submit your plugin** — [duink.com/submit](https://duink.com/submit)
- **Report issues** — [dsh-universe-plugins issues](https://github.com/dsh-universe/dsh-universe-plugins/issues)
